# Django MVC Final Project

A Django-based web application built as the capstone project for my previous coding bootcamp program at Alterra Academy. This project demonstrates the implementation of the MVC (Model-View-Controller) architectural pattern—conceptually recognized as MVT (Model-View-Template) within the Django ecosystem—along with production-ready deployment configurations.

## 📌 Overview

The primary objectives of this project are:

- **Architectural Principles**: Understand and implement the separation of concerns using the MVC/MVT design pattern.
- **Data Management**: Manage relational databases and data modeling effectively using Django ORM.
- **Dynamic Presentation**: Integrate dynamic user interfaces leveraging the Django Template Engine.
- **Deployment Readiness**: Configure environment settings and WSGI/ASGI servers for production deployment.
